# Editing Tools

Load only after the user chooses an editor. App interfaces can vary by version, account, device, language, and image type; use the labels visible to the user.

## Apple Photos on iPhone

Path: `Photos > open photo > Edit > Adjust`.

Common controls on a roughly `-100...+100` scale: Auto, Exposure, Brilliance, Highlights, Shadows, Contrast, Brightness, Black Point, Saturation, Vibrance, Warmth, Tint, Sharpness, Definition, Noise Reduction, Vignette. Also use `Filters` and `Crop` when needed.

Teach in screen order:

1. Open the photo and tap `Edit`.
2. Choose `Adjust`, swipe to the named control, enter/drag to the starting value.
3. State the visual checkpoint after each important adjustment.
4. Tap the image to compare with the original; finish with `Done`.

Apple Photos on iPhone has no general Lightroom-style masks, HSL mixer, tone curve, layers, or calibration. Use global controls, crop, a gentler filter, or Portrait depth controls when the image supports them. Say when selective editing requires another app.

## Instagram Feed Post

Typical path: `Create (+) > Post > choose photo > Next > Filter or Edit`. Labels may differ across versions/accounts.

Available controls commonly include filter strength plus Adjust, Brightness, Contrast, Structure, Warmth, Saturation, Color, Fade, Highlights, Shadows, Vignette, Tilt Shift, and Sharpen.

Teach:

1. Set crop/aspect first.
2. If using a filter, tap it again and set its strength.
3. Open `Edit`, name each control and value in the order used.
4. Recheck skin, highlights, and dark areas before `Next/Share`.

Instagram is suitable for global finishing, filters, and posting. Do not prescribe masks, layers, curves, calibration, or precise HSL controls. For carousels, verify whether edits apply per image.

## Output Pattern

```text
Path: Photos > photo > Edit > Adjust > Highlights
Start: -25
Look for: window/cloud detail returns without turning bright areas gray.
Then: if still clipped, reduce Exposure slightly; if already dull, stop.
```
